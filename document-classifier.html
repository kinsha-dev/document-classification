🤖 Local AI Model (LM Studio)

Setup — three clicks in LM Studio
1
Install LM Studio (skip if already installed)
Download from lmstudio.ai — macOS, Windows, and Linux all supported.
2
Download Gemma 3 (4B) inside LM Studio
Open LM Studio → Discover tab → search gemma-3-4b-it → click Download. ~3 GB.
3
Start the local server (serves the OpenAI-compatible API on port 1234)
LM Studio → Local Server tab (or "Developer" in newer builds) → load Gemma 3 4B → Start Server.
💡 LM Studio shows the exact id to use as "API Model Identifier" on the right when a model is loaded. The trailing :2 is its instance slot — copy it verbatim.
Load in LM Studio: gemma-4-e2b-it:2
The browser talks to the extractor service (Node.js), which calls LM Studio's OpenAI-compatible API at http://127.0.0.1:1234/v1. No CORS dance, no Ollama.
Not tested
⚠ Cannot reach extractor service. Start it with cd extractor-service && npm run dev and make sure LM Studio's local server is running on port 1234.
